Privacy & network

Documents never leave this browser. The only network traffic is loading the code libraries (pdf.js, tesseract.js, pdf-lib, JSZip) from cdn.jsdelivr.net, and on the first OCR the tesseract worker, engine and English language data from the same CDN (then cached locally). Verify below, or in DevTools → Network.

Self-hosting

For air-gapped machines, set localStorage.dealsplit.libs to a JSON object with your own URLs for the keys: pdfjs, pdfjsWorker, tesseract, tesseractWorker, tesseractCore, tesseractLang, pdflib, jszip.
